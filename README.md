## Mansonware

A **Mansonware** cria experiências digitais premium e soluções de software com foco em conversão, automação e execução enxuta.

Este repositório contém o site institucional e comercial da marca, utilizado para apresentar serviços, cases reais e conduzir potenciais clientes ao atendimento direto pelo WhatsApp.

### O que entregamos

- Sites e vitrines digitais premium
- Automações e integrações
- Sistemas, MVPs e SaaS sob medida
- Soluções com WhatsApp, APIs e IA aplicada

## Stack

- Next.js 15
- React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Desenvolvimento

```bash
npm install
npm run dev
```

Validação antes de produção:

```bash
npm run lint
npm run build
```
